
Arquitetura do Projeto - Teste Técnico
Desenvolvido por: Pamela Menezes

🎯 Objetivo
Além de resolver a lógica solicitada, estruturei este teste como um projeto de software real, demonstrando versatilidade em Full Stack (Frontend, Backend e Lógica).

📂 Estrutura de Pastas
O projeto está organizado da seguinte forma:

Teste_Tecnico_Pamela_Menezes/
├── src/
│   ├── javascript/         # (Core) Soluções dos exercícios em JS puro (Node.js)
│   ├── python_scripts/     # (Backend Logic) Soluções alternativas utilizando Python
│   ├── frontend_react_rifa/# (Frontend) Componente React visual para o sistema de rifas
│   └── projeto_django_rifa/# (Backend API) Estrutura base para escalabilidade com Django
├── README_RESPOSTAS.md     # Respostas teóricas e códigos solicitados
└── ARQUITETURA.md          # Este arquivo
🚀 Diferenciais Técnicos Aplicados
1. Frontend com React (src/frontend_react_rifa)
Criei um componente funcional (RifaComponent.jsx) utilizando Hooks (useState) para gerenciar o estado da rifa visualmente. Isso demonstra capacidade de transformar lógica de negócios em interfaces interativas.

2. Backend com Python (src/python_scripts)
Adicionei uma versão da lógica de sorteio utilizando Python, demonstrando proficiência na linguagem principal para Data Science e AI.

3. Escalabilidade (Django)
A pasta projeto_django_rifa representa onde a lógica seria implementada em um cenário de produção, transformando as funções simples em API Endpoints robustos.
